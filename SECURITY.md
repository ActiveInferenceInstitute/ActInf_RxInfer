# Security policy

## Reporting a vulnerability

Please do not disclose sensitive vulnerability details in a public issue or pull request. Use GitHub's private vulnerability reporting for this repository:

<https://github.com/ActiveInferenceInstitute/ActInf_RxInfer/security/advisories/new>

If private reporting is unavailable, open a minimal public issue requesting a private contact channel and do not include exploit details.

## Scope

This repository currently contains a Julia project environment and documentation. Reports about dependencies should include the affected package and version, the smallest reproducible description possible, and any relevant upstream advisory when it is safe to share.

## Supported versions

No released application versions are currently supported. The project metadata currently declares version `0.1.0`; dependency and Julia compatibility are documented in [`Project.toml`](Project.toml).
