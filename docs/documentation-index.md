# Documentation index

Flat index of the long-lived documentation in this repository. The hub is
[`index.md`](index.md), the folder entry point is [`README.md`](README.md), and
the documentation rules are in [`AGENTS.md`](AGENTS.md).

## Guides

- [`getting_started.md`](getting_started.md) — prerequisites, activating the
  project, running the example, and running the gates.
- [`gnn.md`](gnn.md) — the `specs/coin_flip.gnn.md` model declaration, the pin
  record, and the conformance check.
- [`gate.md`](gate.md) — the `./run.sh` arms, their environments, and the CI
  mapping.
- [`resources.md`](resources.md) — upstream RxInfer and Active Inference links.

## Generated records

Files under [`_generated/`](_generated/README.md) are produced by a script and
are never edited by hand.

- [`_generated/gate.md`](_generated/gate.md) — wall time and result per gate
  arm, rendered from `_generated/gate-receipt.json`.
