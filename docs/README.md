# `docs/`

The documentation hub is [`index.md`](index.md); the flat list of long-lived
pages is [`documentation-index.md`](documentation-index.md). The guides are:

- [`getting_started.md`](getting_started.md) — install Julia, activate the
  project, run the example, tests, and gates.
- [`gnn.md`](gnn.md) — the model specification, the parser pin and the
  validation command.
- [`gate.md`](gate.md) — the `./run.sh` arms and the CI mapping.
- [`resources.md`](resources.md) — upstream RxInfer and Active Inference links.

Machine-generated records live in [`_generated/`](_generated/README.md); the
measured gate numbers are in [`_generated/gate.md`](_generated/gate.md).

Authoring rules for this directory are in [`AGENTS.md`](AGENTS.md).
